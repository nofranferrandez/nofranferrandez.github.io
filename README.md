# Contexto del Proyecto: CALCULA.ES
Plataforma de calculadoras fiscales y laborales en España (2026).
Stack: HTML5, Tailwind CSS (CDN/CLI), JavaScript Vainilla.

## Principios de AI & Desarrollo
1. **Mobile-First & Performance:** Interfaz ultra-limpia, responsive y optimizada para la velocidad de carga (Core Web Vitals).
2. **SEO & AdSense Native:** Integrar espacios estratégicos para anuncios y marcado Schema.org sin romper la UX.
3. **UX & Micro-copy:** Sin pop-ups de alerta del navegador (`alert()`). Feedback integrado en la propia UI con Tailwind.
4. **Exactitud Legal:** Validar que los cálculos reflejen la normativa tributaria y laboral española vigente.
